# RizzUp

Paste what she sent. Get a handful of replies that sound like you on a good day — one to tease, one to charm, one to keep short. No pickup lines. No cringe. Built on a free AI.

## Stack

- **Next.js 14** (App Router) + **TypeScript** + **Tailwind CSS**
- Replies generated by the **free Hugging Face inference API** (`router.huggingface.co`), default model **DeepSeek-V3-0324**
- Zero other runtime dependencies

## Features

- Paste a message, press **Enter**, get **3 or 5 vibe-tagged replies** (smooth / witty / cheeky / warm / short)
- **Swap** any single reply without regenerating the whole batch
- **Copy** any reply in one click
- **13 languages** + Hinglish (Roman-script Hindi, never Devanagari unless asked) + auto-detect mode
- Anti-cringe prompt rules: no pickup lines, no generic compliments, no emoji spam, replies are specific to her message
- Token configurable via **Settings panel** or **`.env`** — nothing is stored server-side

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

### Set up your token

1. Create a free token at [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) (no card needed, free tier).
2. Copy `.env.example` to `.env` and paste your token:

```bash
HF_TOKEN=hf_xxxxxxxx
```

Or skip `.env` and paste the token in the app's **Settings** panel — it overrides `.env` and is kept in localStorage only.

### Optional config

| Env var | Default | Purpose |
| --- | --- | --- |
| `HF_TOKEN` | — | Hugging Face token |
| `HF_MODEL` | `deepseek-ai/DeepSeek-V3-0324` | Any chat model enabled on your HF account |
| `HF_URL` | `https://router.huggingface.co/v1/chat/completions` | Inference endpoint |

## API

Both endpoints are POST and take a JSON body; the token can come from the body or `.env`.

**`/api/reply`** — get multiple replies for a message

```bash
curl -X POST http://localhost:3000/api/reply \
  -H "Content-Type: application/json" \
  -d '{"message":"hey are you busy tonight?","language":"auto","count":3}'
```

**`/api/swap`** — regenerate a single vibe

```bash
curl -X POST http://localhost:3000/api/swap \
  -H "Content-Type: application/json" \
  -d '{"message":"hey are you busy tonight?","vibe":"Cheeky tease","language":"auto"}'
```
